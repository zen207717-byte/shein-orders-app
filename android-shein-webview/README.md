# حسابات أم مروان — Android SHEIN WebView (نسخة اختبار)

تطبيق Android تجريبي يفتح SHEIN في WebView ويحوّل بيانات المنتج المرئية إلى شاشة
المراجعة الموجودة في `https://shein-orders-app-1.onrender.com`.

## البناء

1. افتح مجلد `android-shein-webview` في Android Studio.
2. استخدم JDK 17، وانتظر Gradle Sync.
3. ثبّت Android SDK 35 من SDK Manager إذا طلبه Android Studio.
4. اختر `Build > Build APK(s)`.
5. ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.

لا توجد مفاتيح أو كلمات مرور داخل المشروع. تسجيل SHEIN — إذا احتاجه المستخدم — يتم
داخل WebView. التطبيق لا يقرأ Cookies ولا يرسلها إلى نظام أم مروان.

## تدفق الاختبار

1. افتح التطبيق واضغط **فتح SHEIN**.
2. افتح صفحة منتج واختر اللون والمقاس والكمية.
3. اضغط Add to Cart. ينتقل التطبيق للمراجعة فقط إذا ظهرت رسالة نجاح واضحة.
4. إذا لم يكتشفها، اضغط الزر السفلي **حفظ هذه القطعة في نظام أم مروان**.
5. راجع الحقول، سجّل الدخول للنظام عند الحاجة، واختر الزبونة/الطلب ثم احفظ.

## حدود النسخة التجريبية

- يعتمد التقاط الحقول وإشارة Add to Cart على DOM والنص المرئي في SHEIN وقد يتغيران.
- زر الحفظ اليدوي هو المسار الاحتياطي الموثوق؛ لا يدّعي التطبيق نجاح الإضافة للسلة.
- لا ينفذ التطبيق شراءً أو دفعًا، ولا يضغط Add to Cart نيابة عن المستخدم.
- يمنع WebView الانتقال إلى HTTP أو إلى نطاقات غير SHEIN والنظام التجريبي.
